# 共通デザイン

Web UI と出力 HTML は `static/css/tokens.css` を共有します。出力 HTML/PDF には共通定義を埋め込むため、配布したファイルは外部 CSS に依存しません。

藍色は構造と選択、緑は主要操作と許可候補、黄は判断が必要な状態、赤は問題を示します。結果には文字ラベルを併用し、色だけで意味を伝えません。通常の本文・補助情報・罫線・紙面・角丸は共通変数を使ってください。

主要操作は `btn-primary`、補助操作は `btn-secondary`。操作を増やす場合は、初期表示に必要なものを絞り、根拠や詳細を展開できる構成にします。生成と構築テストは共通ナビゲーションで移動します。

追加画面は `web/templates/base.html` を継承し、画面専用 CSS では配置を定義します。新しい色を追加する前に既存の意味色で表せるかを確認してください。図の SVG は単独エクスポートもあるため、必要な表示定義を内部にも保持します。

確認項目：390px の画面幅、キーボードによるフォーカス、文字の折り返し、状態ラベル、詳細の初期折り畳み、操作中の二重実行防止、低モーション設定、オフラインの成果物。
