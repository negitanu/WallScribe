# 出力設定の記憶とHTMLシートの検索

## 出力設定

出力形式、プリセット、カスタムで選んだ項目は、そのブラウザの localStorage に保存され、次回表示時に復元されます。ファイル名、設定内容、アップロードファイル、HA の選択は保存しません。

「設定をリセット」で保存済みの出力設定を削除し、HTML / 運用プリセットに戻せます。ブラウザの保存領域が利用できないときも変換は可能です。不正な保存データは既定の設定にフォールバックします。

「すべて」プリセットは、画面にある全項目を選びます。診断・構造図・通信候補・整理候補・解析範囲も対象です。

## HTMLシート内の検索

検索バーはスクロールに追従します。検索した語句を入力欄に保持し、一致した文字を個別にハイライトします。「前へ」「次へ」で移動し、現在の位置と総件数を表示します。最後から次へ移動すると最初へ戻ります。閉じた詳細内に一致した場合は詳細を開きます。

- `/`: 編集欄以外から検索欄へ移動
- `Enter`: 検索、同じ語句なら次の結果へ移動
- `Shift + Enter`: 同じ語句の前の結果へ移動
- `Esc` または「クリア」: 検索とハイライトを解除

大文字・小文字を区別せず、記号も文字列として検索します。日本語入力の確定中の Enter は検索として扱いません。検索は本文の文字を対象とし、SVG の図中の文字、入力コントロールやスクリプトは対象外です。図の情報は本文の設定表・根拠から検索できます。

検索により設定値を HTML に変換しないため、`<b>` や `&` を含む設定も文字として保持します。人の判断入力や通信候補のフォームを置き換えません。PDF / XLSX に検索バーは追加しません。
